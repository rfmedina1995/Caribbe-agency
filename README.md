# Brothers Envíos website preview

Spanish-language static landing page for client review. Uses HTML, CSS and browser JavaScript, with local image assets. No dependencies or build step.

## Vercel

Import this repository, select Framework Preset **Other**, use the repository root, leave Build and Install Commands empty, and use `.` for Output Directory. The included vercel.json declares these settings.

## Features

Responsive services page, mobile menu, inquiry dialogs, flight inquiry summary, click-to-call and directions. Flight inquiries stay in the browser: there is no booking API, payment processing, lead database, or message delivery backend.

## Assets
